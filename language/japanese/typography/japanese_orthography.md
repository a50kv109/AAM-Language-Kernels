# Japanese Orthography

## Status
- **Epistemic status**: SOURCE_SUPPORTED / RESEARCH_ONLY
- **Scope**: A framework for document-level orthographic variation, not universal global law.

## 1. Hankaku vs Zenkaku
- Orthographic conventions vary by document type, source standard, and environment.
- In some technical settings, half-width ASCII is preferred; in others, full-width forms are more common.
- A repository-level rule must therefore remain context-aware and should not claim a single universal norm.

## 2. Katakana and Latin notation
- Katakana can appear in full-width or half-width forms depending on the system or publication style.
- This is not a blanket instruction for all Japanese documents.

## 3. AAM use
- This layer contributes to the L3/L4 document-processing stage by recognizing that notation is a contextual design decision.
- It is not a claim that the current project includes a fully implemented typography engine.

## 4. Repository note
The orthography guidance is treated as a research extension and should be considered a style-sensitive design aid rather than a normative final standard.
