# Document Terminology

## Status
- **Epistemic status**: RESEARCH_ONLY / SOURCE_SUPPORTED
- **Purpose**: Domain-oriented terminology guidance for a research extension, not a universal standard.

## 1. Date and unit conventions
- Some engineering documents prefer Gregorian-era notation such as `2026年`.
- Other contexts may use different conventions depending on the publication standard or regional practice.
- Do not express these as universal rules for all Japanese technical writing.

## 2. Unit and symbol notation
- Mixed usage of ASCII, half-width, and full-width symbols is common in technical and industrial settings.
- The choice depends on style guides, vendor standards, and the document format.

## 3. AAM application
- This file supports the L3 engineering layer by specifying examples of terminology normalization and notation variation.
- It should not be confused with a repository-wide implementation standard.

## 4. Repository note
This material is kept as context-sensitive guidance, preserving the project’s evidential discipline and avoiding overgeneralized formatting claims.
