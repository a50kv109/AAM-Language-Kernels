# Hebrew Ground-Truth Matrix

This is a proposal for mapping AAM/SOL concepts to future Hebrew evidence records. It is not a validated translation matrix.

| AAM concept | Hebrew mapping | Evidence status | Constraint |
|---|---|---|---|
| SOURCE | No canonical Hebrew equivalent registered | NOT_VERIFIED | Require context, domain, and cited source before mapping |
| CONSTRAINT | No canonical Hebrew equivalent registered | NOT_VERIFIED | Do not infer technical force from a general lexical gloss |
| FLOW | No canonical Hebrew equivalent registered | NOT_VERIFIED | Distinguish literal motion, process, and metaphor |
| STATE | No canonical Hebrew equivalent registered | NOT_VERIFIED | Register aspect, tense, and discourse context separately |
| COMPARE | No canonical Hebrew equivalent registered | NOT_VERIFIED | Preserve the comparison relation and its arguments |
| UNKNOWN | Explicit AAM output state | PROPOSED | Retain unresolved readings; do not select by letter overlap |

No entries are promoted as VERIFIED or SOURCE_SUPPORTED because the supplied packages do not provide cited Hebrew sources or reviewed examples.
